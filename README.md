Excel Power Query Data Transformation & Practice

🧾 Description
This repository contains hands-on practice files demonstrating data cleaning, transformation, and integration techniques using Excel Power Query. The project showcases real-world data preparation workflows including appending,
grouping, merging, and restructuring datasets for analytics readiness.

🎯 Objectives
Perform data cleaning using Power Query
Combine datasets from multiple sources
Practice append & merge operations
Apply grouping & aggregation logic
Transform raw data into analysis-ready format
